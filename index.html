Kairo

Estadísticas de 9 videojuegos en una sola app premium, con partida en vivo de League of Legends.

El problema

Para ver tus estadísticas de LoL, TFT, Brawl Stars, Clash Royale, Clash of Clans, Dota 2, Fortnite, Apex y PUBG tienes que saltar entre webs y apps distintas. Además, las API keys de Riot y Supercell no pueden ir dentro de una app.

Lo que hice

  • App en React Native + Expo con un módulo por juego; las pantallas genéricas no conocen ninguno.
  • Partida en vivo de LoL: equipos, runas, rangos, baneos y cronómetro, con notificaciones push cuando un favorito entra y termina.
  • Backend Node + Express que guarda las keys, cachea, respeta el cupo de Riot y traduce errores. PostgreSQL para los dispositivos.
  • 5 idiomas, perfiles sin conexión, comparar jugadores y compartir perfil como imagen.
  • CI y releases automáticas con GitHub Actions: cada etiqueta genera el APK; los cambios de pantallas llegan sin reinstalar.
  • React Native
  • Expo
  • Node.js
  • Express
  • PostgreSQL
  • Docker
  • GitHub Actions

Coffea IA

Modelado del crecimiento de Coffea arabica: plantas inoculadas con hongos micorrízicos frente a un grupo control.

El problema

Comparar cómo crece el café con y sin hongos micorrízicos exige ajustar modelos no lineales, medir su incertidumbre y leer pruebas estadísticas. Hacerlo a mano es lento y fácil de equivocar.

Lo que hicimos

  • App web en Streamlit que ajusta los modelos Exponencial, Logístico y Gompertz con banda de confianza del 95 %, prueba t de Welch, residuos y reporte en PDF.
  • Datos reales del Cuadro 2 de Aguirre-Medina et al. (2023). Si un modelo no converge, la app lo dice en vez de inventar un ajuste.
  • Validación externa parcial de la metodología con 3 estudios publicados: León-Burgos et al. (2022), Siqueira et al. (1998) y Vallejos-Torres et al. (2021).
  • Versión móvil nativa independiente en Flutter con un backend FastAPI sin estado y gráficas dibujadas a mano, probada en un dispositivo real.
  • Python
  • Streamlit
  • SciPy
  • pandas
  • Plotly
  • Flutter
  • FastAPI

Con Richard Montez, Diego Barrios y Santiago Uribe.

MultiSport Stats

Marcadores, calendarios y clasificaciones de fútbol, NBA, tenis, NHL y Fórmula 1 en una sola web.

El problema

Seguir cinco deportes significa abrir cinco sitios distintos, cada uno con su diseño, sus anuncios y su forma de buscar.

Lo que hicimos

  • Web sin frameworks ni build: HTML, CSS y JavaScript con módulos, publicada en GitHub Pages.
  • Datos de ESPN y Jolpica F1, con respaldo automático en JSON cuando una API falla.
  • Partidos en vivo que se actualizan solos, tablas ordenables, ficha de partido, noticias, buscador y favoritos.
  • Tema oscuro y claro, contraste AA, navegación por teclado y cuentas demo con hash PBKDF2.
  • HTML
  • CSS
  • JavaScript
  • GSAP
  • GitHub Pages

Con Nelson Sierra y Joseph De La Rans.
